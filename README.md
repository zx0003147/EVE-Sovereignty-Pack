# EVE Sovereignty Pack

First-party external Feature Pack for EVE Static Map Planner.

This repository split is currently in development. The Pack targets Feature API contract 1 and will use `dev.evestaticmapplanner:feature-api:1.0.0` as its external API dependency in a later split phase. Its distribution output will be an external `pack.jar`.

Independent build and release preparation are not complete yet.
